Documentation

Guide to using the Arsela Gjonaj website template.

Project Structure Customization Components Build & Deploy

Project Structure

The project is organized as follows:

/
├── public/          # HTML and compiled assets (css, js, images)
├── src/
│   └── scss/        # SASS source files
├── verification/    # Testing scripts
├── package.json     # NPM dependencies
└── README.md        # Project documentation

Customization

To customize the theme, edit the SCSS files in src/scss/.

  • _variables.scss: Define colors, fonts, and bootstrap overrides.
  • _custom.scss: Custom styles for components like cards, hero sections, and doodles.
  • theme.scss: Main entry point that imports Bootstrap and custom files.

Components

We use various custom components:

  • Hero Section: Uses `.hero-section-wrapper` for gradient backgrounds.
  • Cards: `.user-card`, `.feature-card`, `.pricing-card`, `.team-card`.
  • Buttons: `.btn-gradient-pink` for the primary action button.
  • Doodles: Decorative background elements using `.section-doodle` classes.

See Components Page for visual examples.

Build & Deploy

To compile the SCSS to CSS:

npm install
npm run build-css

This generates `public/css/style.css`. The website is static and can be deployed to any static site host.
